## 2. 已拍的方向 B 与四个色值

**方案 B = 主色不动，新增一个蓝紫「对照色」，只用于状态与徽标，面积比 90:10。**

| 变量 | 色值 | HSL | 白字对比度 | 用途 |
|---|---|---|---|---|
| `--accent`（不动） | `#DF5838` | H11.5 S72 L55 | 3.76 ❌ | 品牌动作、选中态、主按钮 |
| `--accent-2`（新增） | `#4A3ADF` | H246 S72 L55 | **7.09** ✅ | 状态与徽标 |
| `--accent-2-dark`（新增） | `#3120C5` | H246 S72 L45 | **9.80** ✅ | 浅底上的文字 |
| `--accent-2-soft`（新增） | `#EFEDFC` | H246 S72 L96 | 与深档字 8.49 ✅ | 状态条底色 |

关键关系（全部实测计算，非估计）：

- 主色 H11.5 ↔ 对照色 H246：**最短弧 125.5°**，属三分色 / 近互补区间。冲击力够，但**不是正互补**。
  （⚠️ 我先前口头报过 234.5°，那是按绕行方向算的，错了。以 125.5° 为准。）
- 两者亮度几乎相同（L54.7 / L55.1）—— 撞的是色相，不是明暗，所以不会互相抢「显眼度」。
- 对照色 vs 成员色：靛蓝 216.6 → 29.4°、紫罗兰 284.3 → 38.3°、天蓝 202.7 → 43.3°，都在 22° 安全线外。
- 对照色 vs 墨绿中性 `#18302D`（H172.5）：**只有 73.5°** → **不许贴着放**，toast 这类墨绿底的东西不要改成对照色。

**被否掉的其他三个方向**（理由也留给你判断对不对）：

- **C · 主色整体换成蓝紫**：撞车彻底消失，但主色与墨绿中性的 ΔH 会从现在的 161°（近正互补）掉到 73.5°，冷加冷，整体从「食欲暖调」变成「工具冷调」。我判断这是拿最好的资产去换次要问题。
- **D · 主色换成品红 `#D322A9`**：对墨绿中性 ΔH 141.5°，撞色关系保住了，白字 4.59 达标。但余量只有 0.09，窗口只有 14.75° 宽。

## 3. 落点：你手上已经有的位置

我原本以为「已上线界面里唯一能改的落点是 `.import-notice` 的进行中状态」。**看完你 14:56 那一版代码之后，这个判断要改 —— 你建的状态色体系才是正确的位置，而且现在就有语义错误。**

### 3.1 `add-place-dialog.tsx` 的 draft tone 系统（首选落点）

你现在有：

```ts
function draftStatus(draft: Draft): { text: string; tone: "muted" | "warn" | "ok" | "bad" } {
  if (draft.stage === "recognizing") return { text: "读图中…", tone: "muted" };
  if (draft.stage === "locating")    return { text: "定位中…", tone: "muted" };
  if (draft.stage === "saving")      return { text: "保存中…", tone: "muted" };
  ...
}
```

配套样式在 `app/globals.css:428–432`：

```css
.draft-badge.is-muted { background: #eef1ee; color: var(--muted); }
.draft-badge.is-ok    { background: #e6f3e9; color: #226c3c;    }
.draft-badge.is-warn  { background: #fdf1e3; color: #8a5a1c;    }
.draft-badge.is-bad   { background: #fceee9; color: #9b4433;    }
```

**问题 1（语义）**：「进行中」被塞进了 `muted`。muted 是灰，表达的是「次要/不可用」，不是「正在忙」。三个进行中状态（读图中/定位中/保存中）和「这个地点不重要」共用同一个灰。

**这正是对照色的天然位置。** 建议加一个 tone：

```css
.draft-badge.is-busy { background: var(--accent-2-soft); color: var(--accent-2-dark); }
```

`draftStatus()` 里把三个 `tone: "muted"` 改成 `tone: "busy"`，并把 `"busy"` 加进返回类型。**改动量：CSS 一行 + TS 四处。** 附带好处：蓝紫在语义上天然表达「处理中」，而灰色会被误读成「已停用」。

### 3.2 底部「投票」tab 徽标（新增元素）

`components/food-map-app.tsx:204` 的「投票」按钮现在完全没有提示 —— 有进行中的投票也看不出来。两种形态我都做了 demo：
