# 问题汇总与决策依据

| 编号 | 问题／原因 | 影响 | 当前方案与验证 | 状态 |
| --- | --- | --- | --- | --- |
| Q1 | 点评微信小程序口令不公开店铺名和坐标；美团／点评网页可能需登录或限制抓取 | 无法稳定从链接还原精确地点 | 取文案、URL 参数或公开标题；没有明确坐标就提示手动选点，保存来源供复核 | 已按已知样例处理，待更多真实样例 |
| Q2 | 苹果地图常用 WGS-84，国内地图常用 GCJ-02 或 BD-09 | 混用会使点位偏移 | 存储统一使用 WGS-84，识别与显示时转换；5 条自动测试通过 | 本地通过，待高德真机核验 |
| Q3 | 国内微信中 OpenStreetMap 瓦片可用性待确认；高德 JS API 需要 Key 和安全码 | 地图可能空白或加载慢 | 增加高德适配及同源安全代理；配置齐全才启用，未配置仍可列表浏览 | 待用户提供配置 |
| Q4 | 本地身份换手机／清理浏览器数据后丢失 | 同一群友可能成为两个成员 | 已预留微信网页授权、OpenID 和会话；需确认已认证公众号及授权域名 | 待公众号条件与真机测试 |
| Q5 | 公开网址可转发，昵称可重名 | 群外人员可能查看或发布内容 | 按用户选择继续公开；服务端加作者和群主权限、一次性群主口令 | 权限本地通过；访问边界为已知取舍 |
| Q6 | 手机原图可能超出上传请求限制 | 413 或上传失败 | 浏览器先压缩大图，提供重试提示；HEIC 取决于手机浏览器解码能力 | 本地通过，待手机相册实测 |
| Q7 | 正式库原有 7 张表，V1.1 新增成员字段与两张表 | 未迁移直接发布会导致接口错误 | 追加 0001 迁移；正式库已升至 9 张表并核对新增字段 | 已完成 |
| Q8 | 删除地点涉及 D1 记录和 R2 照片 | 两个存储无法使用同一事务，可能残留孤立图片 | 先删关联数据库行，再删 R2 对象；对象删除失败写服务端日志，后续可补清理任务 | 已知运维限制 |
| Q9 | 自动化浏览器／curl 请求公开域名被 Cloudflare 拦截 | 无法用自动化客户端完整走正式站点交互 | Sites 部署成功，生产 Worker 日志显示首页和地点接口 200；需群成员在微信真机访问确认 | 待真机核验 |
