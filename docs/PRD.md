# 群聊美食地图 · 产品需求文档

更新：2026-09-30　阶段：已迁移到 WorkBuddy 站点托管并发布，并新增「截图识别 + 自动定位」；手机真机验收、微信配置待完成

## 1. 背景与目标

微信群里的美食和玩乐地址散落在聊天记录、美团或点评分享、地图收藏中，过后难找。产品面向一个微信群，提供适合微信手机端打开的公共网址，让成员把地点放在一起，看到群友的照片、评价和到访记录。

核心流程：打开链接 → 设置昵称和颜色 → 粘贴一条分享 → 核对名称、地址和点位 → 保存；其他成员打开同一网址即可查看和互动。

## 2. 已确认的产品决策

| 事项 | 决策 |
| --- | --- |
| 群与城市 | 首版只服务一个群，空地图默认深圳视角；仍可添加其他城市 |
| 访问范围 | 持有网址即可查看、添加和互动；链接被转发后，群外的人也可以使用 |
| 首页 | 手机端默认简洁列表；顶部切换地图，按「全部／美食／玩乐」筛选 |
| 分享导入 | 每次粘贴一条链接或文案，提取可确定的字段；保存前人工核对点位，不做批量导入 |
| 管理权限 | 作者管理自己的地点和评论、删除自己上传的照片；群主管理全部内容；删除需确认且永久生效 |
| 群主身份 | 一次性私密口令由首位领取者使用，后续不允许再次领取 |
| 成员身份 | 用户选择微信授权作为跨设备识别方案；在公众号条件和网页授权域名确认前沿用浏览器本地身份 |
| 地图底图 | **高德 Web JS API**（2026-10-01 已配置 Key 并实测出图）。高德 Key 缺失时自动回退 OpenStreetMap 组件；但 OSM 瓦片在国内不可用（2026-09-30 实测 3/3 超时），所以**只有高德底图配好才算真正可用**。安全密钥 `AMAP_SECURITY_JS_CODE` 为可选：配了则服务端注入 jscode 走同源代理，没配则直连高德。**底图与「自动定位」是两件事**：定位用百度，与底图无关 |
| 自动定位 | 「名称／地址 → 坐标」由服务端完成，当前用**百度地图**（用户 2026-09-30 决定先用百度，后续再改回高德）。百度只提供定位，不更换前台底图；返回的 BD-09 统一转换为存储用 WGS-84 |
| 截图识别 | 上传美团／大众点评截图，由智谱 `glm-4v-flash` 视觉模型提取店名、菜品品类、平台评分、评分人数、人均价格、地址与原始文字。**截图不上传保存**；识别结果只回填表单供人工核对，不直接入库 |
| 网址 | https://qunliao-food-map.app.workbuddy.host/（2026-09-30 起）。原 ChatGPT Sites 域名被 Cloudflare 边缘拦截，`chatgpt.site` 与 `workers.dev` 均不可用，详见[问题汇总](./问题汇总.md) Q9／Q10 |

## 3. 功能验收标准

### 成员与权限

- 首次打开填写昵称并选颜色；名字和颜色显示在地点、评论、照片和到访成员旁；可再次修改。
- 同一浏览器再次打开保留身份。微信授权启用后，同一微信账号跨设备关联同一成员；未启用时不承诺跨设备身份同步。
- 地点、评论、照片的修改和删除权限由服务端验证。

### 地点与导入

- 列表展示名称、地址、封面、平均分、去过人数和添加者；地图展示彩色点位，点击进入详情。
- 粘贴美团、大众点评或地图分享，识别来源、公开标题、文案和明确坐标；缺坐标时手动选点或填坐标。
- 小程序口令、需登录或反爬的链接明确提示补填，不编造店名与坐标；保留来源便于核对。
- 链接与文案识别不了时可用截图兜底：上传美团／点评截图 → 自动提取字段 → 自动定位。识别不到的字段留空，不猜、不编。
- 自动定位先按店名做 POI 搜索，命中相似度达阈值才采用；否则退回地址解析，地址信息不足时明确返回「未定位」，由用户手动选点。
- 截图识别的原始文字可展开查看，便于核对模型是否读错；平台评分与人均价格独立于群成员评分单独存储。
- 苹果、高德、百度、腾讯地图已知坐标格式统一转换到存储坐标系。
- 保存前必须有地点名和有效坐标。

### 互动与照片

- 每名成员可切换点赞和去过状态，每地点保留一份 1～5 星评分。
- 详情展示谁去过、评分人数、评论作者与时间。
- 支持手机上传照片、缩略图、大图查看；作者或群主可删除。
- 作者可修改和删除自己的评论；删除地点时清理关联互动和照片。

## 4. 非功能与数据

- 优先适配 360～430px 手机视口、微信内置浏览器和触控；地图不可用时列表仍可浏览。
- 成员、地点、互动存 D1，照片存 R2；迁移文件追加维护，不改写已上线旧迁移。
- 链接抓取限制来源域名、响应大小和超时；图片限制格式与大小，客户端压缩常见大图。
- 微信密钥、高德／百度地图密钥、智谱 API Key 和群主口令不得写进仓库，统一放 `site/.dev.vars`（已 Git 忽略）。公开链接不是群成员资格证明，昵称可重名。
- 截图识别只在服务端调用视觉模型，截图本身不经 R2 保存、不入库；识别请求限制体积与超时。
