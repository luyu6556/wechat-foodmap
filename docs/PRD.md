# 群聊美食地图 · 产品需求文档

更新：2026-09-29　状态：V1 本地验证完成，待发布

## 1. 产品目标

让一个微信群的成员把吃喝玩乐地点集中保存在同一张手机地图上，减少聊天记录中链接和地址的丢失。成员可以快速添加、浏览、评价和分享地点，也能看到谁去过。

## 2. 用户与场景

- 分享者：在美团、大众点评或地图应用看到地点，将分享文案和链接粘贴进地图，确认名称和点位后保存。
- 浏览者：打开群链接，以昵称和颜色区分成员，在地图或列表中查看地点、照片、评分、评论和去过的人。
- 到访者：上传自己拍摄的照片、标记去过、点赞、打分和评论。

## 3. V1 范围

| 模块 | 用户故事 | 验收标准 |
| --- | --- | --- |
| 成员身份 | 首次打开时填写昵称并选择颜色 | 保存后可识别自己的操作；再次打开同一浏览器保留身份；可修改昵称和颜色 |
| 地点查看 | 在地图和列表中浏览地点 | 地图点位可点击；列表与详情可查看地址、来源链接和互动信息；手机屏幕无横向溢出 |
| 地点添加 | 粘贴分享文案或链接，补全地点信息 | 能识别支持的链接域名、文案中的名称及地图链接中的坐标；提交前可核对和修改；无法识别时能手动填写并在地图选点 |
| 照片 | 在地点详情上传和查看照片 | 支持移动端相册/拍照，图片可点开查看；文件持久保存 |
| 互动 | 点赞、评分、评论、去过 | 同一成员可切换点赞/去过状态，每人每地点一份评分；评论显示作者和时间 |
| 数据维护 | 保留地点来源与创建者 | 数据存于服务端；失败时有可重试提示；结构便于后续增加群和管理功能 |

## 4. 主流程

1. 群成员打开网址，设置昵称和颜色。
2. 首页直接展示地图及地点列表；点选地点查看详情。
3. 点击“添加地点”，粘贴美团或地图分享内容；系统提取可用字段，用户确认或补全名称、地址和地图点位。
4. 保存后全群可见。成员进入详情，可添加照片、评论、点赞、评分和标记“我去过”。

## 5. 链接导入边界

分享链接格式随平台变化。V1 以“提取 + 人工确认”为准，不在信息不全时猜测位置。地图分享链接若含坐标，自动定位；美团/点评分享链接尝试读取页面标题或分享文案。对需要登录、反爬或仅在 App 内可读的页面，保留原链接并提示手动确认名称和点位。导入能力需要用真实群分享样例验收。

## 6. 非功能要求

- 手机微信内置浏览器优先，触控目标足够大，地图以外可用列表浏览。
- 页面对首次进入者保持简洁，关键操作在首屏可见。
- 地点、评论、互动写入持久数据库，图片写入对象存储。
- 对图片大小、输入长度、链接目标进行限制；只展示纯文本，避免脚本注入。
- 成员身份为轻量昵称身份，不等同微信账号验证；真实群访问范围待确认。

## 7. 已确认的产品决策与样例

- V1 只服务一个微信群。
- 持有链接即可访问；成员自填昵称和颜色，不要求微信登录或加入码。
- 苹果地图样例包含地点名、深圳市南山区地址和 `coordinate=22.579873,113.946445`，可自动预填。
- 大众点评样例是 `#小程序://大众点评美食电影运动旅游门票/A8bd4qMWSBWQT1p`，属于微信小程序口令。口令没有公开的店铺字段或坐标，系统提示补填并在地图选点。
- 空地图初始视角设在深圳；已有地点时自动定位到群内点位。

## 8. 验收记录

- 本地手机预览完成：昵称/颜色设置、苹果地图链接解析、地点添加、点赞、去过、五星评分、评论、照片持久化和大图查看。
- 375px 手机宽度和 1280px 桌面宽度无横向溢出。
- 大众点评小程序口令被识别为需人工补全，避免误识别成店铺名称。

## 9. 暂不纳入 V1

商家数据批量爬取、价格与营业时间自动同步、微信账号授权、跨群推荐、商家排序运营后台。是否进入后续版本由实际使用反馈决定。
