## 2026-09-30 · 迁移到 WorkBuddy 站点托管并发布

### 为什么换托管

- `workers.dev` 这条路**已被证据排除，不需要再注册 Cloudflare 账号去验证**：本机绕过代理直连 `https://example.workers.dev/` 超时 12s 且拿不到 IP；`example.workers.dev` 经阿里 DNS 解析得 `108.160.169.179`（Dropbox 网段）、本机默认解析得 `104.244.43.231`（Twitter 网段），均为伪造地址；GreatFire 记录其自 2022-05-10 起持续被屏蔽，2026-09-21 仍为已屏蔽。
- `chatgpt.site` 的拦截是 Cloudflare 边缘策略，不是本地网络问题：该域名 DNS 正常解析到真实 Cloudflare IP，绕过代理直连返回 403，说明连接成功但被应用之前拒绝。改前端或重部署同一域名都不会有用。
- 选定 WorkBuddy 站点托管：`*.workbuddy.host` 解析到腾讯云北京 CLB `49.233.240.214`，属国内 IP，无需备案、无需自有域名、无额外账号。

### 架构：数据层未改写

- `wrangler dev --local` 下 D1 就是本地 SQLite 文件、R2 就是本地目录，因此 16 条 `/api/*` 路由、服务端权限模型、`drizzle` 迁移与原生 SQL **全部原样保留**，没有引入登录系统。
- 这也回避了一个产品冲突：WorkBuddy 云服务数据库是托管 PostgreSQL，且约束「未登录只能读显式公开表，私有数据必须先登录」——采用它会强迫群成员注册登录，与「打开即用、只填昵称」冲突。

### 新增 `scripts/sandbox-serve.mjs`

1. 状态目录默认 `$HOME/.qunliao-food-map/state`，**位于项目目录之外**：部署会把项目目录打包上传，状态放在项目内会在每次重新部署时被覆盖。

4. `.gitignore` 增加 `.dev.vars` / `.dev.vars.*`；群主口令只以 SHA-256 哈希形式存在于该文件，不进仓库。

## 2026-10-01 · 配色与首屏优化、底图切换到高德

### 需求来源

- 用户反馈成员代表色**太暗**（原方案大量使用深色，白字可读但整体发闷），要求提亮；同时要求做一轮移动端 UI 优化。
- 用户提供高德 Web JS API Key，要求把底图从 OpenStreetMap 换成高德（OSM 瓦片在国内实测不可用，底图一直是空白，见问题汇总 Q3）。

### 配色：为什么不能只"提亮"

- 「提亮」与「白字可读」对同一块背景色是**互斥**的：白字要满足 WCAG 4.5:1，背景相对亮度必须压在 L ≲ 52%；再提亮就只能改用深色字。
- 因此方案是**双管齐下**：把 8 个代表色统一收敛到 L 48.0～52.9%（对比度 ≥4.62:1），并让字色**按背景亮度自动切换**（`contrastText()` 返回 `#18302d` 或 `#ffffff`）。这样颜色确实亮了，字也始终可读。

### 实现

- 新增 `lib/color.ts` 作为**唯一色彩源**：`MEMBER_COLORS`（砖红／青碧／靛蓝／紫罗兰／琥珀／玫红／草绿／天蓝）、`MEMBER_COLOR_NAMES`、`contrastText()`、`memberColorStyle()`、`normalizeColor()`。
- 旧色迁移用**代码级映射**（`LEGACY_COLOR_MAP` + `normalizeColor()`）而不是 SQL：写入接口 `/api/members`、`/api/me` 与微信回调都会把旧值归一成新色，**旧数据不需要批量改库**，且映射可回退。未知或非法值回落到默认色。
- 把 `.member-avatar`、`.profile-illustration span`、`.color-option` 里写死的 `color:#fff` 全部移除，改为 `style={memberColorStyle(color)}`；`components/food-map-app.tsx`、`place-detail.tsx`、`profile-dialog.tsx`、`map-canvas.tsx`、`amap-canvas.tsx` 同步接入。
- UI 优化：色块触控目标 38→44px（对齐 iOS 最小触控尺寸）、配色块补 `aria-label`（中文色名）、清理 20 个已无引用的死 CSS 类（`.brand`、`.list-add-button`、`.places-panel` 等）。

- `app/api/map/config/route.ts` 不再强制要求 `AMAP_SECURITY_JS_CODE`：有 `AMAP_WEB_KEY` 就返回 `provider=amap`，并用 `useProxy` 标记是否配置了安全密钥（配了走同源代理 `app/api/map/[...proxy]` 由服务端注入 jscode，没配则前端直连高德）。
